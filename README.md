# 金城烽烟 · 铁桥密信

这是一个无需构建、无需数据库、无需外部图片链接的 GitHub Pages 静态网页包。

## 一键上传

把本文件夹里的 **全部内容** 上传到仓库根目录，确保 `index.html` 位于仓库根目录。GitHub 仓库中选择 `Settings → Pages → Deploy from a branch → main → /(root) → Save`，等待页面发布即可。

也可以把整个文件夹压缩后解压到仓库根目录。不要只上传 `index.html`：`data.js`、`app.js`、`styles.css` 和 `assets` 文件夹都是网页的一部分。

## 玩家测试路径

从首页开始，推荐依次完成：中山桥 N06–N16 → 白塔山 N17–N21 → 水车博览园 N22–N29 → 城内接头 N30–N32 → 酒泉路314号 N33–N37 → 实景彩蛋 N38–N40。

网页会自动保存进度。证物库、案件墙、档案模式和额外探索均可单独打开。现场无法查看碑刻、水车或弹痕时，使用每道题下方的档案模式，不会卡死。

## 内容边界

故事中的密卷、维修工、暗号、爆破计划、伍修权汇报与“守住铁桥”的行动是虚构演绎；结尾将虚构剧情与可核对的历史事实分开。网页内的当代照片和剧情复原图也已在图注中区分。

## 结尾历史回顾视频

N40 结尾提供了“烽烟金城历史回顾——兰州抗日期间的中山桥”视频入口。预览图使用卷宗内的中山桥配图；点击按钮会在新页面打开你提供的微信文章，视频在微信文章页面中播放。
